# Strategicka_hra_Tower_Defense_s_editorem_map

Vytvořte v prostředí Visual Studio (jazyk C#) desktopovou aplikaci pro Windows Forms s verzováním na GitHubu. Aplikace bude 2D real-time strategická hra typu Tower Defense, ve které hráč staví obranné věže podél cesty a brání svou základnu před vlnami procházejících nepřátel.
Hra bude vykreslována pomocí rozhraní GDI+ s využitím plynulého překreslování (Double Buffering) a herní smyčky řízené časovačem. Součástí aplikace budou základní typy věží (např. rychlá a silná věž) a více druhů nepřátel s odlišnou rychlostí a počtem životů.
Pro projekt bude vytvořen mřížkový editor map, ve kterém si učitel nebo student může poskládat vlastní trasu pro nepřátele a rozmístění stavitelných ploch, přičemž mapy se budou ukládat a načítat ze souborů ve formátu JSON nebo XML.
